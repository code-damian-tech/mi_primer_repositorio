Este proyecto tiene como objetivo principal ser usado a manera de entrenador espacial para quienes esten interesados en saber cual es el comportamiento de la llama en caida libre, tanto en el espacio, como en la Tierra.
Todo esto servira para prevenir cualquier tipo de accidente o tragedia que pueda ocurrir por el desconocimiento de dicho comportamiento. Para hacerlo un poco mas dinamico, hemos realizado algunas actividades interactivas donde el usuario sea cual sea su edad, pueda realizar y en caso de equivocarse en algun item, pueda tener una retroalimentacion sobre el tema
